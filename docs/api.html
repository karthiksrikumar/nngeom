API reference

Everything below is importable from the top level: import nngeom as ng. Functions that move a model through parameter space always restore the original weights, and every stochastic routine accepts a seed.

#models

The Model class gives every framework the same geometric interface: a flat parameter vector, a scalar loss field, its gradient, and a Hessian-vector product.

MemberDescription
Model(obj, loss_fn, name)Wrap a torch.nn.Module (with loss_fn(module, batch)) or a dict of numpy arrays (with loss_fn(params, batch)).
Model.from_function(params, loss_fn, grad_fn=None)Framework-free model from numpy parameters. Without grad_fn, gradients use central finite differences.
Model.load(path, module, loss_fn)Load a torch state_dict checkpoint into an architecture instance and wrap it.
parameters_flat() / set_parameters_flat(v)Read or move the model's position in parameter space as one 1-D vector.
loss(batch) / gradient(batch) / hvp(batch, v)Scalar loss, flat gradient, and Hessian-vector product at the current point. Torch models use exact autograd double-backward for hvp.
layer_names() / layer_shapes() / layer_norms()Named parameter blocks and their L2 norms.
spectral_norms()Largest singular value of each weight matrix. Their product bounds the Lipschitz constant; spikes flag amplifying layers.
stable_ranks()Stable rank per weight matrix: how many directions each layer really uses.

#lossland

FunctionDescription
linear_interpolation(a, b, batch, steps, extend)Loss along the straight line between two models. .barrier_height() on the result tests linear mode connectivity.
random_slice_1d(model, batch, span, steps, seed, normalize)Loss along a filter-normalized random direction through the current weights.
plane_slice_2d(model, batch, span, steps, directions, seed)Loss over a 2-D plane: the classic landscape visualization. Directions default to two random orthogonal, filter-normalized vectors.
sharpness(model, batch, radius, n_samples, seed)Random-perturbation sharpness: how much the loss rises at a fixed relative radius.
basin_width(model, batch, threshold, ...)How far the model can move before loss rises by threshold, averaged over directions.
interpolation_smoothness(curve)Second-difference energy of a 1-D slice: 0 for a straight line, large for a bumpy path.
loss_barrier_matrix(models, batch, steps)Pairwise barrier heights between many checkpoints. Near-zero entries share a basin.
bezier_path(a, b, control, batch, steps)Loss along a quadratic Bezier path through a chosen control point.
find_low_loss_path(a, b, batch, steps, iters, seed)Searches for a curved low-loss path between two models (mode connectivity). Reports straight vs curved barrier and a connected verdict.

#curvature

Matrix-free. Everything here needs only model.hvp, so it works on models where the full Hessian could never be materialized.
FunctionDescription
hessian_spectrum(model, batch, k, method, trace, seed)One-call curvature summary: top eigenvalues plus a trace estimate. method is "lanczos" or "power".
lanczos_spectrum(model, batch, m, seed)Lanczos tridiagonalization with full reorthogonalization; approximates the extreme eigenvalues.
power_iteration(model, batch, k, iters, seed)Top-k eigenpairs with deflation. Returns eigenvectors, needed for eigenvector_overlap.
hutchinson_trace(model, batch, n_samples, seed)Stochastic estimate of tr(H): average curvature over all directions.
curvature_along(model, batch, direction)Second directional derivative along any chosen direction.
layerwise_curvature(model, batch, n_samples, seed)Trace estimate restricted to each layer block: which layers carry the curvature.
SpectrumResult object: top_eigenvalue, condition_ratio(), negative_fraction() (saddle signal), plot().

#representations

All metrics take plain (n_examples, dim) numpy matrices, so they work with any framework.

FunctionDescription
extract_activations(module, inputs, layers, flatten)Capture activations from named submodules of a torch model via forward hooks.
linear_cka(X, Y) / rbf_cka(X, Y)Centered Kernel Alignment: rotation- and scale-invariant similarity between two representations of the same examples.
cka_matrix(reps, kernel)Pairwise CKA between named layers; plot with visualize.plot_cka_matrix.
svcca(X, Y, variance_kept)SVD denoising followed by canonical correlation: similarity of the informative subspaces.
procrustes_distance(X, Y)Residual after the best rotation aligning X to Y. 0 means same shape up to rotation.
subspace_overlap(X, Y, k)Overlap of top-k principal subspaces via principal angles.
uniformity(X, t, seed)Wang-Isola uniformity on the unit sphere. More negative means features are better spread out.
linear_probe_score(X, labels, l2, train_fraction, seed)Closed-form ridge probe with train/test split: how linearly decodable the labels are.
neuron_alignment(X, Y)Greedy one-to-one neuron matching by correlation: did two seeds learn the same features?
representation_drift(before, after)Per-layer CKA, Procrustes, and norm change between two snapshots on the same inputs.
anisotropy(X, n_pairs, seed)Expected cosine between random pairs: how cone-shaped the space is.
collapse_score(X)In [0, 1]: 1 means everything mapped to nearly one direction.
class_geometry(X, labels)Centroids, per-class radius, within/between scatter, separation ratio.
representation_summary(X, labels)One-call profile combining the metrics above.

#manifolds

FunctionDescription
pca(X, k)SVD-based PCA: projections, components, explained variance ratio.
effective_rank(X)Entropy-based effective rank of the covariance.
participation_ratio(X)How many dimensions carry meaningful variance.
intrinsic_dimension_twonn(X)TwoNN estimator: the manifold dimension of a point cloud, robust to curvature and density.
knn_graph(X, k)k nearest neighbor indices per point.
neighborhood_preservation(X, Y, k)Fraction of kNN neighborhoods preserved between two spaces.
local_tangent_dimension(X, k, variance_threshold)Per-point local dimension via neighborhood PCA.
random_projection(X, k, seed)Johnson-Lindenstrauss projection: shrink huge activation matrices while preserving distances.
outlier_scores(X, k)z-scored kNN distance per point: geometric outliers are often mislabeled or shifted inputs.
class_manifold_dimensions(X, labels)TwoNN dimension of each class's own manifold.
manifold_summary(X, k)One-call structural profile.

#trajectories

MemberDescription
Trajectory.from_models(models) / from_vectors(vectors)Build a path from checkpoints or raw flat vectors.
path_length() / net_displacement() / tortuosity()Distance traveled, start-to-end distance, and their ratio (1 means straight).
directional_persistence() / step_cosines()Do consecutive steps agree? Negative means oscillation.
phase_changes(threshold)Checkpoints where the optimization direction sharply changed: learning-rate drops, instability.
norm_growth()Global parameter norm at each checkpoint.
layerwise_drift()Per-layer distance from the first checkpoint over time.
pca_projection(k) / plot()Project the path into its principal plane for visualization.
loss_along_trajectory(models, batch)Loss at each checkpoint.

#dynamics

FunctionDescription
gradient_alignment(model, batches)Mean pairwise cosine between batch gradients: signal vs conflict.
gradient_noise_scale(model, batches)tr(Cov(g)) / ||E[g]||²: large values suggest a bigger batch size would help.
fisher_diagonal(model, batches)Empirical Fisher diagonal: per-parameter importance (EWC-style).
fisher_layer_importance(model, batches)Fisher mass per layer.
sam_sharpness(model, batch, rho)SAM-style worst-case loss rise after one ascent step along the gradient.
local_linearity(model, batch, radius, n_samples, seed)How well a first-order model predicts nearby losses: trust-region quality.

#compare

FunctionDescription
compare_models(a, b)Global L2/cosine distance plus per-layer drift. .top_changed_layers(), .summary().
task_vector(base, tuned)The fine-tune as a vector: tuned minus base.
apply_task_vector(model, v, scale)Task arithmetic: add (or subtract) a task vector in place.
task_vector_alignment(v1, v2)Do two fine-tunes push the model the same way (cosine)?
model_soup(models, weights)Parameter averaging of checkpoints that share a basin (check with loss_barrier_matrix first).
eigenvector_overlap(spec_a, spec_b, k)Did the curvature directions change between checkpoints? Needs spectra from power_iteration.

    return float(...)

#surfaces

Sample any scalar over parameter space, not just loss: accuracy, entropy, a custom metric.

FunctionDescription
scalar_field_1d(model, field_fn, direction, span, steps)field_fn(model) along a direction.
scalar_field_2d(model, field_fn, d1, d2, span, steps)field_fn(model) over a plane.

#report

report = ng.analyze(
    model,
    batch,                      # enables loss + curvature sections
    checkpoints=[...],          # enables trajectory section
    representations={...},      # enables representation sections
    labels=y,                   # enables class geometry
    depth="standard",           # "quick" | "standard" | "full"
)
print(report.summary())
report.to_json("report.json")
report.to_html("report.html")

The report automatically warns about: saddle points (negative Hessian eigenvalues), representation collapse, extreme anisotropy, very sharp basins, models not at a local minimum, and oscillating optimization, and it suggests the next experiments to run.
