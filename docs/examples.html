Examples

Every script lives in examples/ and runs standalone. All but the last need only numpy, so you can explore the whole library before installing any deep learning framework.

python examples/quadratic_demo.py

quadratic_demo.py

The full tour on a model with known geometry. Builds a quadratic model whose Hessian is planted, so every measurement can be checked against ground truth: the spectrum estimate recovers the planted eigenvalues, the interpolation curve shows no barrier, and the automated report ties it all together. The best place to see the whole API in one file.

spec = ng.hessian_spectrum(model, batch, k=5)
# top eigenvalue (true 20.0): 20.000
# trace estimate  (true 47.55): 48.06

compare_finetunes.py

Checkpoint comparison workflow. Simulates a base model and two fine-tunes, then answers the questions you actually ask after fine-tuning:

  • What changed, layer by layer? (compare_models)
  • Do the two fine-tunes push the model the same way? (task_vector_alignment)
  • Are they in the same basin? (loss_barrier_matrix)
  • Can I average them into a soup? (model_soup)
  • If the straight path has a barrier, is there a curved valley? (find_low_loss_path)

training_dynamics.py

Watch real gradient descent geometrically. Trains the same model with SGD at a safe learning rate and at one just under the stability limit, then compares the two runs: tortuosity, directional persistence, phase changes, gradient noise scale, SAM sharpness, and local linearity. The unstable run shows negative persistence (oscillation) and a wandering path; the stable run moves straight.

representation_geometry.py

Representation health checks. Builds synthetic layer activations with known structure and shows how each tool exposes it: CKA vs SVCCA vs Procrustes on a rotated layer, linear probes, class manifold dimensions, collapse and uniformity on a planted rank-1 collapse, outlier hunting with a planted outlier, neuron matching across permuted "seeds", and a before/after drift report.

nlp_geometry.py

All ten NLP tools in one script. Uses synthetic hidden states shaped exactly like a real transformer's residual stream, with planted effects for each tool to find: a divergence layer for prompt_divergence, two sense clusters for polysemy_score, a repetition loop for the attractor score, and a topic shift for token_novelty. Swap in states from output_hidden_states=True and everything applies to your model.

torch_example.py

The real thing. Requires pip install nngeom[torch]. Trains a small MLP on synthetic data, then runs exact autograd Hessian spectra, loss slices, activation extraction with forward hooks, layer CKA, trajectory analysis over training snapshots, and exports the full HTML geometry report.

acts = ng.extract_activations(net, X, layers=["0", "2", "4"])
report = ng.analyze(model, batch, representations=acts, labels=y.numpy())
report.to_html("torch_geometry_report.html")
