A field guide to
model geometry

nngeom measures, visualizes, and reasons about the shape of neural networks: loss landscapes, curvature, representation structure, training trajectories, and token geometry for language models. A trained model is not only a function. It is a surface with basins and ridges, a cloud of points with a manifold, a path through a space with a shape you can survey.

Why nngeom

Deep learning is full of geometric language: the model found a flat minimum, the representations collapsed, the fine-tune drifted. nngeom turns those metaphors into measurements. Every analysis returns numbers you can compare, log, and test, and the automated report flags suspicious geometry (saddle points, collapse, oscillating optimizers) instead of only drawing plots.

Field index

Nine survey instruments, each pointed at a different part of a model's shape.

lossland Loss landscapes. Interpolation barriers, 2D slices, sharpness, basin width, curved low-loss paths between models. curvature Curvature. Hessian spectra via Lanczos and power iteration, Hutchinson trace, per-layer curvature. Matrix-free, so it scales. representations Representations. CKA, SVCCA, Procrustes, linear probes, collapse and anisotropy detection, neuron matching, drift reports. manifolds Manifolds. Intrinsic dimension (TwoNN), effective rank, kNN graphs, outlier scores, random projections. trajectories Trajectories. Path length, tortuosity, directional persistence, phase-change detection, layerwise drift over training. dynamics Optimization dynamics. Gradient noise scale, batch gradient alignment, empirical Fisher, SAM sharpness, local linearity. compare Model comparison. Per-layer drift, task vectors and their alignment, model soups, Hessian eigenspace overlap. nlp NLP geometry. Ten token-geometry tools: token trajectories, prompt divergence, polysemy, repetition attractors, novelty. report Automated report. One call profiles a model, warns about bad geometry, and exports a shareable HTML report with figures.

Installation

pip install nngeom            # core, numpy only
pip install nngeom[torch]     # + PyTorch adapter (autograd HVPs, hooks)
pip install nngeom[viz]       # + matplotlib plotting
pip install nngeom[all]       # everything
No framework lock-in. The core library depends only on numpy. Every analysis works on plain parameter dictionaries via Model.from_function, and all representation and NLP tools take ordinary numpy arrays, so hidden states from PyTorch, JAX, or TensorFlow models all work the same way.

Quickstart

import nngeom as ng

# wrap a PyTorch model with a loss closure
model = ng.Model(net, loss_fn=lambda m, b: F.cross_entropy(m(b[0]), b[1]))

# one call: loss geometry, curvature, warnings, suggested next steps
report = ng.analyze(model, batch, depth="standard")
print(report.summary())
report.to_html("geometry_report.html")

A few one-liners that answer real questions:

# Is my fine-tune in the same basin as the base model?
ng.linear_interpolation(base, tuned, batch).barrier_height()

# How sharp is the minimum I converged to?
ng.hessian_spectrum(model, batch, k=5).top_eigenvalue

# Did my representations collapse?
ng.collapse_score(activations)

# Are my minibatch gradients mostly noise?
ng.gradient_noise_scale(model, batches)

# Can I average my fine-tunes into a soup?
soup = ng.model_soup([tune_a, tune_b])

# Where do two prompts diverge inside my language model?
ng.prompt_divergence(hidden_a, hidden_b)["divergence_layer"]

Core concepts

ConceptWhat it isWhere
ModelA network viewed as a point in parameter space: flat parameter vector, loss, gradient, and Hessian-vector product behind one interface.models
Curve / SurfaceThe loss (or any scalar) sampled along a line or plane in parameter space.lossland, surfaces
SpectrumTop Hessian eigenvalues and eigenvectors: the local curvature of the loss.curvature
RepresentationAny (n_examples, dim) activation matrix, treated as a point cloud with structure.representations, manifolds
TrajectoryA sequence of checkpoints: training as a path through parameter space.trajectories
DirectionA probe vector: random, filter-normalized, gradient, eigenvector, or concept-based.probes
Hidden statesA (n_layers, n_tokens, dim) residual stream: the raw material of NLP geometry.nlp

Design principles

  • Geometry first. Models are points, checkpoints are trajectories, losses are surfaces, activations are manifolds.
  • Matrix-free. All curvature analysis needs only Hessian-vector products, never a full Hessian.
  • Reproducible. Every stochastic routine accepts a seed; results carry their settings as metadata.
  • Honest. Reports surface warnings and approximation limits, not only headline numbers.
  • Restorative. Every routine that moves a model through parameter space restores the original weights, even on error.
